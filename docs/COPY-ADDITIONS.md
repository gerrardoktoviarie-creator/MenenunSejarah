# Teks Tambahan di Luar Kamus Salin (PRD §7.1)

| Lokasi | Teks |
|---|---|
| Beranda, log boot baris 3 | `> motif: kosong` / `> motif: tersimpan (SL-xxxxxx)` (status nyata) |
| Beranda, tombol | `LEWATI` |
| Arsip, eyebrow (h1) | `[ ARSIP SANDI // ANATOMI ALAT TENUN ]` |
| Arsip, penanda | `01 LUNGSI` · `02 PENGGULUNG` · `03 SISIR` · `04 KAIN` |
| Arsip, bagian 2 | **PENGGULUNG = MEMORI**: Penggulung lungsi menampung ratusan helai benang yang belum ditenun. Seperti memori, ia menyimpan bahan mentah yang dibaca satu baris setiap kali pakan dilempar. · `[ 0 0 0 0 0 0 0 0 ] · BARIS YANG BELUM DIBACA` |
| Arsip, bagian 3 | **SISIR = EKSEKUSI**: Setiap hentakan sisir merapatkan satu baris pakan ke kain. Satu hentakan, satu baris selesai, mirip detak jam yang memberi tanda bahwa instruksi berikutnya boleh dijalankan. · `[ 1 0 1 0 1 0 1 0 ] · SATU HENTAKAN, SATU BARIS` |
| Arsip, bagian 4 | **KAIN = KELUARAN**: Kain yang tergulung adalah hasil program: deretan keputusan naik dan turun yang kini terbaca sebagai motif. Baca kain dari bawah ke atas, dan kamu membaca kodenya. · `[ 1 1 0 0 1 1 0 0 ] · KELUARAN TERSIMPAN` |
| Playground | `UNDO`, `REDO`, `CERMIN`, `PRESET GEOMETRIS`: `BELAH KETUPAT`, `ZIGZAG`, `PAPAN CATUR`, `SILANG` |
| Playground, tanpa JS | Kanvas biner butuh JavaScript. Nyalakan JavaScript untuk memprogram motif. |
| Playground, storage diblokir | Penyimpanan perangkat tidak tersedia (mode privat?). Motifmu tetap tersimpan selama sesi ini, tetapi hilang bila halaman dimuat ulang. |
| Dampak, pengantar | Motif yang kamu tenun kini punya piagam. Simpan, bagikan, lalu dukung pengrajin yang menenun sungguhan. |
| Dampak, perangko | `POS PUSAKA // 12 × 12` · `ARSIP BINER` |
| Dampak, cap pos | `SANDI LELUHUR` · tanggal · `TERCAP` |
| Dampak, pesan | Menyiapkan PNG… · PNG diunduh: … · PNG gagal dibuat. Coba tekan UNDUH PNG sekali lagi. · Peramban ini belum bisa membagikan berkas, jadi PNG diunduh sebagai gantinya. |
| Dampak, CTA kosong | Kanal mitra belum ditetapkan. |
